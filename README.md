## ✨ Features & Enhancements

- **Modern Cyber-Arcade Aesthetic**: Deep dark theme with glassmorphism cards, ambient glowing mesh backgrounds, and sleek typography using Google Fonts (`Outfit` & `Plus Jakarta Sans`).
- **Radiant Target Design**: Multi-layer luminous sphere with inner specular highlights and pulsing locator rings.
- **Dynamic Difficulty**: The target smoothly shrinks as your score climbs, demanding sharper accuracy.
- **Procedural Web Audio Engine**: Zero-dependency synthesized sound effects powered by the Web Audio API (hit tones with ascending combo pitch, low-time countdown ticks, fanfare chords for high scores, and audio mute toggle).
- **Juicy Visual FX**: Real-time particle explosions on target hits, celebratory confetti for record scores, and floating combo badges (`+1`, `🔥 COMBO`).
- **Performance Breakdown**:
  - Live Score, Countdown Timer & Progress Bar
  - Combo / Streak tracking
  - All-Time Personal Best (saved in `localStorage`)
  - End-game Clicks Per Second (CPS) analysis and Rank Badges (e.g. *Godlike Reflexes*, *Lightning Sharpshooter*, *Speed Demon*)
- **Share Your Score**: One-tap score sharing using the Web Share API or automatic clipboard copy.
- **Ultra-Responsive Controls**: Zero-latency pointer event handling optimized for mobile touchscreens and desktop mice alike, plus Spacebar shortcut support.
